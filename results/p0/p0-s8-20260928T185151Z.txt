# Design: weights = coopmat B operand (lane owns one weight column -> ONE sub-scale per lane per 16x16 tile),
#   activations s8 = A operand, f32 scale per row per 256-K block. Accumulate per 16-K WMMA (C=0), then
#   acc_i32 += t * sc (per 16), facc_f32 += float(acc_i32) * d * sa once per 256. Unconditional clamped prefetch.
# Variants: base = no sub-scale (d*sa per 256 only; ceiling of a requantised per-256 s8 format)
#   sub = int mul (ACO emits quarter-rate v_mul_lo_u32 -> 47 TOPS), sub24 = OpenCL.std s_mad24 via
#   GL_EXT_spirv_intrinsics (-> v_mad_i32_i24, full rate), subf = per-16 float cvt+fma,
#   q6k* = same but unpacking real 210-B block_q6_K (ql/qh 6-bit -> s8, sc, d) while staging to LDS,
#   dual = timing emulation of the exact two-plane split w'=sc*q=128*hi+lo (2 WMMA, no per-16 VALU).
# LDS banks (bk=32 s8, 8 dwords/row, 64 banks, 16 lanes per b128 phase): pad=4 (stride 12) -> coopMatLoad of 16 rows
#   hits 16 disjoint 4-bank groups (conflict-free), b128 staging stores 2-way; pad=0 is the reverse. XOR swizzle fixes both.
